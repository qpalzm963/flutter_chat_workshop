# 講師使用手冊：Server + 儀表板

全班共用的聊天 Server，同時提供講師儀表板。只用 `dart:io`，不用裝任何套件。

> 學員不需要讀這份文件，也不會改 Server。協議說明給學員看的版本在根目錄 [README.md](../README.md)。

## 啟動

```bash
cd server
dart run server.dart --admin=Vince --data=state.json
```

| 參數 | 預設 | 說明 |
| :--- | :--- | :--- |
| `--admin=<名字>` | 未設定 | 講師的暱稱。用這個名字登入 App 才能下 `/drop Amy`、`/zombie @all` 這類**指定對象**的指令；儀表板「以講師身分發言」也會用這個名字 |
| `--data=<檔案>` | 只放記憶體 | 狀態存檔（訊息、房間、分房、水位線、行為等級、延遲）。**課程跨週一定要帶**，否則重啟後 `seq` 從 1 開始，學員本地 DB 會對不上 |
| `--port=<n>` | `8080` | 改了的話學員 App 也要改 `app/lib/config.dart` |
| `--level=raw\|echo\|ack` | `raw` | 起始行為等級（也能在儀表板切換）。⚠️ 如果 `--data` 檔已存在，會以存檔裡的等級為準，這個參數不會生效 |

啟動後終端機會印出一行摘要（port、admin、level、存檔路徑）。上課時可以把這個視窗開著，連線、斷線、`/drop`、重複送出都會即時印出來，很適合投影給學員看。

## 課前準備清單

1. **跑自檢**：`dart run smoke_test.dart`。它會開一台臨時 Server（port 18080），逐項驗證課堂會用到的行為，最後印出 `ALL PASSED ✅`。
2. **查講師電腦的區網 IP**，寫在白板或簡報上，讓用實機的學員帶 `--dart-define=HOST=<IP>`：
   ```bash
   ipconfig getifaddr en0      # macOS（Wi-Fi）
   ```
3. **防火牆**：macOS 第一次跑 `dart` 時跳出「允許連入連線」，請按允許。不然實機會連不上。
4. **確認等級**：第 1 堂開場用 `raw`、第 1～3 堂用 `echo`、第 4 堂起用 `ack`（見下方逐堂表）。
5. **延遲歸零**：全域延遲也會被存檔。上次課後沒關的話，這次一開場所有訊息都會慢。
6. **講師自己也開一台 App**，用 `--admin` 那個名字登入，就能在聊天室直接下指定對象的指令。

## 儀表板

瀏覽器開 `http://localhost:8080/admin`（`/` 也可以），每秒自動更新。

| 區塊 | 可以做什麼 |
| :--- | :--- |
| 頂部列 | 切換行為等級（純字串 / 回音 / ACK）、設定全域延遲（毫秒） |
| 學員 | 在線狀態、是否 zombie、被拒絕剩幾秒、目前分到哪間房。每人可按 `/drop`、`/zombie`、拒絕連線 N 秒；也可以一次對 `@all` |
| 分房 | 一鍵「私人房 / 兩兩一組 / 大廳」；勾選學員建立自訂群組（會推 `room_added`） |
| 重連時間軸 | 最近 3 次 `/drop` 之後 0～40 秒內，每個人的重連嘗試（綠＝連上、紅＝被拒）。用來對比有沒有 Jitter |
| 房間 | 點一間房之後：以講師身分發言、灌 N 則訊息、看每人的已讀水位線（可以直接設定）、看最近 50 則 |

> [!WARNING]
> 儀表板**沒有任何驗證**，同網段的人只要知道網址都能打開。課堂上記得不要投影網址，或請學員不要亂點。

### 分房規則

| 模式 | 行為 |
| :--- | :--- |
| 私人房 | 每位學員一間 `private:<名字>`。`Amy` 和 `Amy-2` 算同一個人，會在同一間（以 `-` 前面的字當作同一人） |
| 兩兩一組 | 以「人」為單位依名字排序兩兩配對，房號 `pair:A:B`；人數是奇數時，最後一組 3 人 |
| 大廳 | 全部在線學員進 `lobby` |
| 自訂群組 | 勾選的人加入新群組 `group:<n>`，**不會**離開原本的分配房（第 8 堂「活動拉群」用） |

- 前三種是「搬家」：學員會離開舊的分配房。沒帶 `room_id` 的訊息（第 1～7 堂）會送到新的分配房。
- 新學員第一次連上會自動進自己的私人房。
- 只有**在線**的學員會被分房。分房前先確認大家都連上了。

## 逐堂操作

| 堂 | 課前 | 課中 / 驗收 | 結尾鉤子 |
| :--- | :--- | :--- | :--- |
| 1 | 等級 `raw`；分「私人房」 | 學員升級成 JSON 之後，切到 `echo`；最後切「大廳」讓全班互傳 | 對某位學員按 `/zombie`：畫面正常但收不到訊息 |
| 2 | 等級 `echo` | 學員自己 `/zombie`，看 15 秒內是否自動連回；講師按 `/drop @all`，打開「重連時間軸」對比有／無 Jitter | 學員斷線時在大廳發言 → 連回來後看不到（留到第 7 堂） |
| 3 | 等級 `echo` | 選一間房灌 1000 則，測列表效能 | 全域延遲設 2000 ms，自己的訊息要等 2 秒才出現 |
| 4 | 開場**切 `ack`**，延遲維持 2000 ms 示範 | 示範完延遲歸零；學員用 `/delay`、`/fail` 驗收 | 學員殺掉 App 重開，訊息全不見 |
| 5 | **分「兩兩一組」，第 5～7 堂都不要再換房** | 對某位學員「拒絕連線」，讓他確認離線也能秒開 | 學員重裝 App，又是空的 |
| 6 | **每個兩人房各灌 300 則**（見下方批次指令） | 學員重裝 App 進房，確認看得到最新一頁，往上滑沒有重複 | 拒絕某學員連線，請他的夥伴趁機傳 3 句 |
| 7 | — | 學員按 `/drop`，看機器人的 3 句有沒有自動補回；拒絕連線 30 秒，期間學員送 3 則，解除後要依序送達、不重複 | 勾 3 個人建自訂群組 → 學員 App 還沒有房間列表，看不到 |
| 8 | 解除換房限制 | 建自訂群組，學員的房間列表要即時出現；學員之間互相私聊 | — |
| 9 | — | 把 Amy 的已讀設成 50 → 對該房灌 300 則 → Amy 的列表顯示未讀 300、進房停在分隔線；群組裡顯示「已讀 N」 | — |
| 10 | 不需要 Server | — | — |

> [!IMPORTANT]
> 第 5～7 堂學員的 DB 還沒有 `room_id`，這三堂中途換房會讓學員本地資料錯亂。第 8 堂的 DB 升版會把舊訊息收進「當時分配的房間」。

### 在聊天室裡下指令

講師用 `--admin` 那個名字登入 App 之後，可以加上對象：

```
/drop Amy        /drop @all
/zombie Amy      /zombie @all
```

- 聊天室裡的 `@all` 不包含講師自己；儀表板按鈕的 `@all` 則是所有在線的人（講師的 App 也會被踢）。
- 對象必須在線，否則講師會收到 `error`。
- 學員加了對象會收到「指定對象只開放講師」。

### 用 curl 批次操作

儀表板的按鈕背後都是 `POST /admin/action`，需要重複操作時可以直接打 API：

```bash
# 第 6 堂課前：每個兩人房各灌 300 則（需要 jq）
for r in $(curl -s localhost:8080/admin/state | jq -r '.rooms[] | select(.kind=="pair") | .id'); do
  curl -s -X POST localhost:8080/admin/action -d "{\"action\":\"flood\",\"room\":\"$r\",\"n\":300}"
done
```

| `action` | 其他欄位 | 對應按鈕 |
| :--- | :--- | :--- |
| `level` | `level`: `raw` / `echo` / `ack` | 行為等級 |
| `delay` | `ms` | 全域延遲 |
| `drop` / `zombie` | `user`（名字或 `@all`） | `/drop`、`/zombie` |
| `reject` | `user`, `seconds` | 拒絕連線 |
| `assign` | `mode`: `private` / `pairs` / `lobby` | 分房 |
| `group` | `name`, `users`（陣列） | 自訂群組 |
| `say` | `room`, `text` | 以講師身分發言 |
| `flood` | `room`, `n` | 灌訊息 |
| `read` | `room`, `user`, `seq` | 設定已讀（可以往回設） |

目前狀態：`GET /admin/state`（加 `?room=<id>` 會一併回傳該房最近 50 則）。

## 存檔與重置

- 帶 `--data` 時，有變動就每 2 秒寫一次檔（先寫 `.tmp` 再改名，不怕寫到一半壞掉）；按 `Ctrl+C` 結束時也會再存一次。
- 會存：訊息、房間與成員、分房、水位線、行為等級、全域延遲。
- 不存：誰在線、zombie、拒絕連線中。重啟後大家本來就會自動重連。

| 情境 | 做法 |
| :--- | :--- |
| 跨週繼續上課 | 用同一個 `--data` 檔重啟即可，`seq` 會接續 |
| 新一梯次從頭開始 | 停 Server → 刪掉 `state.json` → 重新啟動 → **請學員刪掉 App 重裝**（或清除 App 資料） |
| 不小心沒帶 `--data` 重啟 | 跟「從頭開始」一樣，學員都要清掉本地資料，否則本地的 `seq` 會比 Server 大，補洞和已讀都會錯亂 |

> [!TIP]
> `state.json` 裡有學員的對話內容，建議加進 `.gitignore`，不要 commit。

## 常見狀況

| 現象 | 原因 / 處理 |
| :--- | :--- |
| 學員實機連不上 | 不在同一個網段、`HOST` 帶錯，或 macOS 防火牆擋掉了 `dart` |
| 學員回報「同名已在線」 | 他另一台還開著，或 hot restart 留下的舊連線。Server 每 5 秒做一次協議層 ping，會自動清掉死掉的連線，等幾秒再連就好 |
| 名字裡有 `-` 的兩個人被分到同一間私人房 | `-` 前面的字被當成同一人（例如 `Mary-Jane` 和 `Mary`）。請學員改名 |
| 一開場訊息就很慢 | 上次的全域延遲還留在存檔裡。到儀表板把延遲設回 0 |
| `--level` 沒生效 | 存檔裡的等級優先，請改到儀表板切換 |
| 學員送 JSON 但收到純文字 | 等級還在 `raw`。切到 `echo` 或 `ack` |
| 學員收不到 ACK | 等級還在 `echo`（第 1～3 堂行為）。第 4 堂開場要切到 `ack` |
